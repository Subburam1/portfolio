## 📝 Customization Guide

### Adding a Resume PDF
1. Place your resume PDF file (named `resume.pdf`) in the same directory as `index.html`
2. The "Download Resume" button will automatically work

### Updating Personal Information
Edit the `index.html` file:
- Change name, email, phone number in the hero section and contact section
- Update education details in the About section
- Modify project descriptions and highlights
- Update certification list as needed

### Changing Colors
Edit `styles.css`:
- Background color: `background-color: #ffffff;` (white)
- Text color: `color: #000000;` (black)
- All major color values are at the top of the file for easy customization

### Adding More Content
The structure is flexible and ready for additions:
- Add more projects to the projects section
- Add more certifications
- Extend skill cards with proficiency levels

## 🌐 Deploy to GitHub Pages

### Step 1: Create a GitHub Repository
1. Go to [GitHub.com](https://github.com) and log in
2. Create a new repository named `username.github.io` (replace `username` with your GitHub username)
3. Initialize with a README

### Step 2: Upload Your Files
1. Clone your repository locally:
   ```bash
   git clone https://github.com/your-username/your-username.github.io.git
   ```
2. Copy `index.html`, `styles.css`, and `script.js` into the cloned folder
3. Add your `resume.pdf` file

### Step 3: Push to GitHub
```bash
cd your-username.github.io
git add .
git commit -m "Add portfolio website"
git push origin main
```

### Step 4: Enable GitHub Pages
1. Go to your repository settings
2. Scroll to "Pages" section
3. Select "main" branch as source
4. Click "Save"

Your portfolio will be live at: `https://your-username.github.io`
